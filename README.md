# Allpa Tech Crece

Pagina estatica para explicar el programa Allpa Tech Crece a avicultores y guiarlos hacia una ruta de compra.

## Estructura

- `index.html`: experiencia principal, hero, ruta y product finder.
- `script.js`: logica del diagnostico interactivo.
- `styles.css`: estilos mobile-first.
- `assets/`: imagen hero en PNG y WebP.
- `productos/`: paginas de venta, retoma y fichas bloqueadas para productos futuros.

## Publicacion en GitHub Pages

1. Sube estos archivos al branch que uses para publicar.
2. En GitHub, entra a `Settings > Pages`.
3. Selecciona el branch y la carpeta raiz.
4. Publica. La home esperada es `index.html`.

Los enlaces de venta internos pueden reemplazarse por URLs reales de tienda cuando existan. Los CTA actuales abren WhatsApp con mensajes prellenados. Las fichas marcadas como `En produccion` o `Proximamente` no prometen compra inmediata.
